Issuance checklist

  1. Register the university wallet.
  2. Have the administrator approve it.
  3. Have the student register their wallet.
  4. Enter and check the award details.
  5. Keep the downloaded JSON certificate.

The document is downloaded before the transaction starts. Keep it if publication is interrupted; the registry recovery tool can publish it later.
